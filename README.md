A systematic assessment of the relationship between different features of climate variability and use of remittances in Sub-Saharan Africa.

To reproduce paper results, download the contents of the Models folder. To create the environmental data from scratch -- including e.g., frequency, NDVI mean, etc -- download the Environmental Data Processing folder. To create the social data from scratch -- including e.g., wealth index, household size -- download the Social Data Processing folder.

ORIGINAL DATA: 
-Household data are sourced from World Bank: https://microdata.worldbank.org/index.php/catalog/95
-SPEI data both for the globe, and subset for Africa, can be directly downloaded here: https://catalogue.ceda.ac.uk/uuid/ac43da11867243a1bb414e1637802dec/
-Original daily NDVI files can be downloaded from: https://www.ncei.noaa.gov/metadata/geoportal/rest/metadata/item/gov.noaa.ncdc:C01558/html
