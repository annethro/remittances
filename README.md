"Monetary transfers may be related to patterning in climate events, not just single extreme events"
Anne Pisor, Danielle Touma, J. Hope Guin, James Holland Jones
In press, Climatic Change, https://doi.org/10.1007/s10584-026-04249-7

Data and code maintained by Anne Pisor and Danielle Touma

## Reproducing our results
To reproduce paper results, download the contents of the Models folder. 

## Reproducing our data wrangling
To create the analysis data from scratch, do the following:
- Reproduce the social data pipeline -- including e.g., wealth index, household size -- by downloading the Social Data Processing folder.
- Reproduce the environmental data pipeline -- including e.g., frequency, NDVI mean, etc. -- by downloading the Environmental Data Processing folder.
- Merge the data by downloading the Merge folder. 

## Raw data sources
- Household data are sourced from the World Bank; for example, find the Burkina Faso data at: https://microdata.worldbank.org/index.php/catalog/95
- SPEI data both for the globe, and subset for Africa, can be directly downloaded here: https://catalogue.ceda.ac.uk/uuid/ac43da11867243a1bb414e1637802dec/
- Original daily NDVI files can be downloaded from: https://www.ncei.noaa.gov/metadata/geoportal/rest/metadata/item/gov.noaa.ncdc:C01558/html
